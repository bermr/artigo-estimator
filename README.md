# 📐 Artigo Estimator

Ferramenta simples para estimativas rápidas de projeto desenvolvida pelo escritório [Artigo Arquitetura e Design](https://www.instagram.com/artigoarquitetura/#)

## 🚀 Visão Geral

Este projeto foi feito para tornar o processo de estimativa de custos mais ágil, especialmente em reuniões ou momentos iniciais de briefing com o cliente. Ele permite simular valores baseados em categorias de intervenção, padrões de acabamento e área total do projeto.

⚙️ Funcionalidades

A calculadora possui os seguintes campos:

### 🧾 Tipos de serviço
- **Projeto**
- **Consultoria**
- **Projeto arquitetônico**

### 📏 Variáveis de entrada
- **Área total (m²)** — insira a metragem do projeto
- **Número de visitas** — quantidade de visitas previstas
- **Área molhada?** — custo diferenciado para ambientes como cozinhas e banheiros
- **Urgente ou obra em andamento?** — fator que influencia na precificação
- **Complexidade** — escolha entre `Baixa`, `Média`, `Alta` ou `Especial`
- **Acompanhamento da obra?** — adiciona um percentual extra ao valor

### 💸 Resultado
- Cálculo automático com base nas escolhas
- Valor final exibido instantaneamente
- Interface leve e intuitiva

## 🛠️ Tecnologias

- HTML + CSS + JavaScript (puro)
- Sem dependências externas
- Design leve e responsivo
